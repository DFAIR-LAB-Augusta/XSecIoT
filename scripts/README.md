# scripts — Data Processing and Evaluation Utilities

This directory contains helper scripts for working with datasets, logs, and evaluation outputs produced by FIRCE and FIRE.

All scripts are intended to be run from the repository root using `uv`.

## Overview

The scripts in this directory support common workflows:

- labeling unlabeled flow datasets
- merging multiple CSV outputs
- aggregating performance metrics across runs
- extracting structured statistics from logs

These utilities are designed to operate on outputs generated by FIRCE pipelines and simulation runs.

## Files

`labeling.py`  
Applies labels to unlabeled flow datasets. Typically used to assign ground truth labels after data collection.

`merge.py`  
Merges multiple CSV files into a single dataset. Useful for combining sharded outputs or multiple experiment runs.

`overall_perf_stats.py`  
Aggregates performance metrics across runs and produces summary statistics such as accuracy, precision, recall, and F1 score.

`overall_stats_scraper.py`  
Parses log files and extracts structured performance statistics into a tabular format.

`run_sim.sh`  
Shell helper for running FIRCE simulations. This wraps common CLI arguments for convenience.

`run_xseciot.sh`  
Convenience script for running broader XSecIoT workflows.

`slurm.sh`  
Example SLURM script for running experiments on HPC systems.

## Requirements

- Python 3.11 or newer
- `uv`

Install dependencies from the repository root:

```bash
uv sync
```

## Usage

All scripts should be executed from the repository root.

General pattern:

```bash
uv run scripts/<script_name>.py [arguments]
```

To view available options:

```bash
uv run scripts/overall_perf_stats.py --help
```

## Common Workflows

### Label a dataset

```bash
uv run scripts/labeling.py \
  --dataset_path datasets/CEFlows/unlabeled
```

### Merge labeled datasets

```bash
uv run scripts/merge.py \
  --dataset_path datasets/CEFlows/mc_labeled
```

### Aggregate performance statistics

```bash
uv run scripts/overall_perf_stats.py
```

Optionally specify a log directory:

```bash
uv run scripts/overall_perf_stats.py \
  --log_dir logging
```

### Extract structured stats from logs

```bash
uv run scripts/overall_stats_scraper.py
```

Or with a specific directory:

```bash
uv run scripts/overall_stats_scraper.py \
  --log_dir logging
```

## Notes

* Input datasets are typically stored under `datasets/`
* Logs and outputs are typically written under `logging/`
* Scripts assume consistent column formats produced by FIRCE pipelines
* If errors occur, verify that upstream pipeline outputs match expected schema

## HPC Usage

The `slurm.sh` script provides an example for running experiments in a SLURM-managed environment. Modify resource requests and commands as needed for your cluster.

## Development Notes

These scripts are lightweight utilities and are not part of the installed package API. They are intended for research workflows and experimentation.
